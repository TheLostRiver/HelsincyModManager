# 0.1.0-alpha.0 发布验收清单

本清单用于 `0.1.0-alpha.0` 首个 Alpha 版本发布前的人工验收，覆盖范围与判定标准来自
`docs/release/发布与产物说明.md` 的「发版前检查清单」与 Tier 1 支持要求，以及
`docs/TESTING.md` 的「发布与打包」章节。

自动化测试（`scripts/verify.ps1`）已覆盖单元与契约层，本清单只列**必须人工确认**的项目：
真实文件系统写入、安装器行为、跨进程与设备相关路径。

## 使用方式

- **先读 `ALPHA_0_MANUAL_TEST_GUIDE.md`**：其中包含开始前必做项（Debug Log 默认关闭，
  不先开启会让日志失去大部分诊断价值）、容易测漏的点和日志导出边界。
- 逐项执行，在 `结果` 栏填 `通过` / `失败` / `跳过`，失败项必须记录现象与复现步骤。
- 遇到 P0 判定为失败时**停止发布**，不要继续走后续章节。
- 按 `docs/TESTING.md`「结果记录约定」记录：已执行、未执行、风险三类，不把"应该能通过"写成"已通过"。

## 环境前置

测试必须在**干净环境**进行，不能复用开发机的既有应用数据。

- [ ] 使用真实 Windows x64 环境（Tier 1 目标平台）
- [ ] 准备一份**可丢弃的** MHW:I 游戏目录副本，不要用你自己在玩的存档与游戏本体
- [ ] 准备一份可丢弃的存档目录副本
- [ ] 记录测试环境：Windows 版本、是否 4K/缩放、游戏版本

> 高风险提示：本清单包含游戏目录写入、覆盖、删除和存档恢复路径。
> 在真实游戏目录上测试前先做外部备份，不要依赖被测程序自身的备份功能作为唯一保险。

## G. 首轮验收发现缺陷的复验（P0）

以下三项是 `0.1.0-alpha.0` 首轮真机验收发现并已修复的缺陷，**必须逐项复验**。
自动化只能断言代码与配置文本，渲染结果与窗口几何都只能真机确认。

| # | 项目 | 判定标准 | 结果 |
|---|---|---|---|
| G-a1 | 导入无元数据的真实 Mod 包（如"黑骑士大剑.zip"） | 列表显示中文名，不是 `mod-import-<时间戳>` | |
| G-a2 | 导入含特殊字符 / 超长 / emoji 文件名的包 | 名称被净化但仍可辨认，列表不破版 | |
| G-a3 | 同名包重复导入两次 | 第二条显示为 `<原名> (2)`，两条都落库，安装仍按内部 ID 区分 | |
| G-a4 | 给既有 Mod 追加新版本（revision） | **展示名不被新包文件名改写，也不被追加序号** | |
| G-a5 | 删掉 `(2)` 那条后再导入同名包 | 补回 `(2)`，不跳到 `(3)` | |
| G-a6 | 手动把某 Mod 改名成与另一个相同，再导入同名包 | 追加序号避开这两个名字，不报错 | |
| G-b1 | 默认窗口首次启动 | 右侧状态栏在位，无需滚动 | |
| G-b2 | 默认窗口首次启动 | 主题切换菜单与设置齿轮可见 | |
| G-b3 | 1920×1080 @100% / @125%、1366×768 三种配置 | 窗口完整可见，不被任务栏遮挡，居中 | |
| G-b4 | 手动拖动窗口过 1181/1180 边界 | 右侧栏在 1180 处收起，状态栏不换行 | |
| G-b5 | 手动拖动窗口过 1061/1060 边界 | 主题与齿轮在 1060 处才隐藏，状态栏不超出 64px 高 | |
| G-c1 | **先在配置档页滚到底**，再让引导推进到末步 | 高亮完整覆盖后台备份开关，不只覆盖"重新检查" | |
| G-c2 | 手动进设置页再开引导 | 无回归 | |
| G-c3 | 开启系统"减少动态效果"后重跑引导 | 高亮仍正确 | |

> G-b3 是本轮最关键的一项：`preventOverflow` 的钳制发生在建窗期，无法自动断言。
> G-c1 的"先滚到底"是竞态触发条件，直接跳步验不出问题。
> G-a4 锁住的是一条容易回归的边界：文件名只能作展示名候选，不得污染版本继承判据。
> G-a6 走的是自动测试覆盖不到的路径——重名可以由用户改名造成，不只由导入造成。

## 不在本次 Alpha 验收范围

以下项目**明确不验收**，Release notes 中应作为已知限制说明：

- 应用内自动更新（无 updater，见 `docs/release/UPDATER_PLAN.md`）
- 安装包代码签名（尚无平台签名策略，Windows 会提示未知发布者）
- Linux / Steam Deck 实机验证（无设备，不得承诺支持）
- macOS（非一等支持目标）
