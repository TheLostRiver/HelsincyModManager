# 赞助与支持

Helsincy Mod Manager 是开源项目。赞助用于支持持续开发、测试环境、文档维护和发布相关成本，
完全自愿，不影响软件功能、更新、问题处理顺序或开源协作。

## 赞助说明

- 赞助不会解锁专属功能，也不会改变 HMM 的开源许可和安全边界。
- 赞助者不需要提供游戏目录、存档、日志、Steam ID 或其他玩家数据。
- 功能建议和缺陷报告请使用 [GitHub Issues](https://github.com/TheLostRiver/HelsincyModManager/issues)。
- 安全问题请按照 [安全策略](../SECURITY.md) 中的方式报告，不要在公开 Issue 中披露敏感细节。

## 其他支持方式

不便赞助也没有关系。提交清晰的问题反馈、帮助验证不同 Windows 环境、改进文档或参与代码 review，
同样能直接帮助项目。
